SLIDE 2: What is Procedural Generation?
----------------------------------------
- Creating content algorithmically
- Using code instead of manual placement
- Advantages:
  * Saves time
  * Creates variety
  * Enables dynamic content
  * Reduces file size
- Examples: Minecraft, No Man's Sky

SLIDE 3: Why Generate Walls?
-----------------------------
- Manual placement: Tedious, error-prone
- 100+ bricks per wall
- Multiple walls needed
- Easy to adjust (rows, columns, spacing)
- Consistent results
- Enables patterns and variations

SLIDE 4: Grid-Based Generation
-------------------------------
- Organize objects in rows and columns
- Use nested loops (row loop, column loop)
- Calculate position mathematically
- Consistent spacing
- Easy to modify

SLIDE 5: Nested Loops
----------------------
```csharp
for (int row = 0; row < rows; row++)
{
    for (int col = 0; col < columns; col++)
    {
        // Create brick at (col, row)
        Debug.Log($"Position: ({col}, {row})");
    }
}
```

Outer loop: Rows (Y axis)
Inner loop: Columns (X axis)

SLIDE 6: Calculating Positions
-------------------------------
- Start position: Bottom-left of wall
- Brick size: Width and height
- Spacing: Gap between bricks
- Formula:
  * X = startX + (column × (brickWidth + spacing))
  * Y = startY + (row × (brickHeight + spacing))

SLIDE 7: Centering the Wall
----------------------------
- Calculate total width
- Offset start position
- Center on origin (0, 0, 0)

```csharp
float totalWidth = columns * (brickWidth + spacing);
float startX = -totalWidth / 2f;
```

SLIDE 8: Instantiate Function


SLIDE 9: Quaternion.identity
-----------------------------
- Represents "no rotation"
- Quaternion: 4D rotation representation
- identity = (0, 0, 0, 0) rotation
- Euler angles: (0, 0, 0) degrees
- Use for default rotation

SLIDE 10: Parent-Child Hierarchy
---------------------------------
- Organize generated objects
- Parent: Container object
- Children: Generated bricks
- Benefits:
  * Clean hierarchy
  * Easy to delete all
  * Transform inheritance
  * Organization


SLIDE 11: Transform.SetParent
------------------------------
- Better than direct assignment
- Options for world/local space

```csharp

// Use local position

```

SLIDE 12: Local vs World Position
----------------------------------
World Position:
- Absolute position in scene
- Independent of parent

Local Position:
- Relative to parent
- Changes with parent transform

SLIDE 13: Brick Alternation Pattern
------------------------------------
- Offset every other row
- Creates brick-laying pattern
- More realistic wall
- Formula: if (row % 2 == 1) offset by half brick

```csharp
float xOffset = (row % 2 == 1) ? brickWidth / 2f : 0f;
```

SLIDE 15: Calculating Brick Position
-------------------------------------
```csharp
Vector3 GetBrickPosition(int x, int y)
{
    Vector3 brickSize = brickPrefab.transform.localScale;
    float totalWidth = columns * (brickSize.x + spacing);
    Vector3 startPos = transform.position;
    startPos.x -= totalWidth / 2f;
    
    float xOffset = (y % 2 == 1) ? (brickSize.x + spacing) / 2f : 0f;
    
    return startPos + new Vector3(
        x * (brickSize.x + spacing) + xOffset,
        y * brickSize.y,
        0
    );
}
```

SLIDE 21: Wall Generator Code Template
---------------------------------------
```csharp
void GenerateWall()
{
    Vector3 brickSize = brickPrefab.transform.localScale;
    Vector3 startPos = CalculateStartPosition();
    
    for (int y = 0; y < rows; y++)
    {
        for (int x = 0; x < columns; x++)
        {
            Vector3 position = GetBrickPosition(x, y, startPos, brickSize);
            Brick3D brick = Instantiate(brickPrefab, position, Quaternion.identity);
            brick.transform.SetParent(bricksParent, false);
            SetBrickColor(brick);
        }
    }
}
```

SLIDE 25: Implementing Patterns
--------------------------------
```csharp
bool ShouldPlaceBrick(int x, int y, WallPattern pattern)
{
    switch (pattern)
    {
        case WallPattern.Normal:
            return true;
        case WallPattern.Checkerboard:
            return (x + y) % 2 == 0;
        case WallPattern.Diagonal:
            return x == y;
        case WallPattern.Random:
            return Random.value > 0.3f;
        default:
            return true;
    }
}
```
