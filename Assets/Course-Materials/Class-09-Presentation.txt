SLIDE 2: User Input in Games
-----------------------------
- Input: How players interact
- Types: Keyboard, mouse, gamepad, touch
- Essential for interactivity
- Unity has two input systems:
  * Old Input Manager (legacy)
  * New Input System (modern)

We'll use the New Input System!

SLIDE 3: Old vs New Input System
---------------------------------
Old Input Manager:
- Simple but limited
- Input.GetKey(), Input.GetMouseButton()
- Hard-coded input bindings
- Difficult to rebind

New Input System:
- More powerful and flexible
- Action-based (abstract)
- Easy rebinding
- Multi-device support
- Better for modern games

SLIDE 4: Installing Input System
---------------------------------
Steps:
1. Window > Package Manager
2. Unity Registry (dropdown)
3. Find "Input System"
4. Click Install
5. Unity may ask to restart
6. Enable in Player Settings if prompted

Both systems can coexist!

SLIDE 5: Input System Concepts
-------------------------------
Key concepts:
- Actions: What player wants to do
- Bindings: Physical input for action
- Action Maps: Groups of actions

Example:
- Action: "Fire"
- Bindings: Left Mouse, Gamepad Right Trigger
- Map: "Gameplay"

SLIDE 6: Creating Input Actions (Code)
---------------------------------------
We'll create actions in code:
```csharp
using UnityEngine.InputSystem;

private InputAction clickAction;

void Awake()
{
    clickAction = new InputAction();
    clickAction.AddBinding("<Mouse>/leftButton");
}
```

Simple and direct for our needs!

SLIDE 7: Input Action Lifecycle
--------------------------------
```csharp
void Awake()
{
    // Create and configure
    clickAction = new InputAction();
    clickAction.AddBinding("<Mouse>/leftButton");
    clickAction.performed += OnClick;  // Subscribe
}

void OnEnable()
{
    clickAction.Enable();  // Start listening
}

void OnDisable()
{
    clickAction.Disable();  // Stop listening
}
```

SLIDE 8: Callback Context
--------------------------
```csharp
using UnityEngine.InputSystem;
using static UnityEngine.InputSystem.InputAction;

void OnClick(CallbackContext context)
{
    // context.started - Button just pressed
    // context.performed - Action completed
    // context.canceled - Button released
    
    if (context.performed)
    {
        Debug.Log("Click performed!");
    }
}
```

SLIDE 9: Mouse Position
------------------------
Getting mouse position:
```csharp
using UnityEngine.InputSystem;

void GetMousePosition()
{
    // Screen coordinates (pixels)
    Vector2 mousePos = Mouse.current.position.ReadValue();
    
    Debug.Log($"Mouse at: {mousePos}");
}
```

Screen coordinates:
- (0,0) = Bottom-left
- (Screen.width, Screen.height) = Top-right

SLIDE 11: Creating RayCastManager
----------------------------------
Our input handler script:
```csharp
using UnityEngine;
using UnityEngine.InputSystem;
using static UnityEngine.InputSystem.InputAction;

public class RayCastManager : MonoBehaviour
{
    private Camera playerCamera;
    private InputAction clickAction;
    
    void Start()
    {
        playerCamera = Camera.main;
    }
    
    void Awake()
    {
        clickAction = new InputAction();
        clickAction.AddBinding("<Mouse>/leftButton");
        clickAction.performed += OnMouseClick;
    }
    
    void OnEnable()
    {
        clickAction.Enable();
    }
    
    void OnDisable()
    {
        clickAction.Disable();
    }
    
    void OnMouseClick(CallbackContext ctx)
    {
        Debug.Log("Mouse clicked!");
        Vector2 mousePos = Mouse.current.position.ReadValue();
        Debug.Log($"Position: {mousePos}");
    }
}
```

SLIDE 12: Input Delays
-----------------------
Prevent rapid clicking:
```csharp
private float lastClickTime;
private float clickDelay = 0.2f;

void OnMouseClick(CallbackContext ctx)
{
    if (Time.time - lastClickTime < clickDelay)
        return;  // Too soon, ignore
    
    lastClickTime = Time.time;
    
    // Process click
    ProcessClick();
}
```

SLIDE 18: Handling Multiple Inputs
-----------------------------------
```csharp
private InputAction moveAction;

void Awake()
{
    moveAction = new InputAction();
    moveAction.AddCompositeBinding("2DVector")
        .With("Up", "<Keyboard>/w")
        .With("Down", "<Keyboard>/s")
        .With("Left", "<Keyboard>/a")
        .With("Right", "<Keyboard>/d");
}

void Update()
{
    Vector2 movement = moveAction.ReadValue<Vector2>();
}
```

SLIDE 19: Action Phases
------------------------
```csharp
clickAction.started += ctx => Debug.Log("Started");
clickAction.performed += ctx => Debug.Log("Performed");
clickAction.canceled += ctx => Debug.Log("Canceled");
```

For button:
- started: Button down
- performed: Button down (same frame)
- canceled: Button up

SLIDE 24: Input Best Practices
-------------------------------
- Create actions in Awake
- Enable in OnEnable
- Disable in OnDisable
- Use meaningful action names
- Add input delays for UX
- Support multiple devices
- Cache references

SLIDE 25: Complete RayCastManager
----------------------------------
```csharp
using UnityEngine;
using UnityEngine.InputSystem;
using static UnityEngine.InputSystem.InputAction;

public class RayCastManager : MonoBehaviour
{
    [SerializeField] private float clickDelay = 0.2f;
    
    private Camera playerCamera;
    private InputAction clickAction;
    private float lastClickTime;
    
    void Start()
    {
        playerCamera = Camera.main;
    }
    
    void Awake()
    {
        clickAction = new InputAction();
        clickAction.AddBinding("<Mouse>/leftButton");
        clickAction.performed += OnMouseClick;
    }
    
    void OnEnable() => clickAction.Enable();
    void OnDisable() => clickAction.Disable();
    
    void OnMouseClick(CallbackContext ctx)
    {
        if (Time.time - lastClickTime < clickDelay)
            return;
        
        lastClickTime = Time.time;
        
        Vector2 mousePos = Mouse.current.position.ReadValue();
        Debug.Log($"Click at: {mousePos}");
        
        // Next class: Raycast from here!
    }
}
```
