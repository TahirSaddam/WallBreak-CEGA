SLIDE 2: What are 3D Primitives?
---------------------------------
- Basic 3D shapes built into Unity
- Building blocks for prototyping
- Types: Cube, Sphere, Capsule, Cylinder, Plane, Quad
- Created via: GameObject > 3D Object menu
- Each has default collider and renderer

SLIDE 3: The Cube Primitive
----------------------------
- Most common primitive
- 1x1x1 unit size by default
- 6 faces, 8 vertices, 12 edges
- Perfect for: Walls, boxes, buildings, bricks
- Our game will use cubes for bricks!

SLIDE 4: The Plane Primitive
-----------------------------
- Flat surface, 10x10 units by default
- Only visible from one side (top)
- Perfect for: Ground, floors, platforms
- Efficient for large flat surfaces
- We'll use this for our game ground

SLIDE 5: Understanding Meshes
------------------------------
- Mesh = 3D shape made of vertices, edges, faces
- Mesh Filter: Stores the mesh data
- Mesh Renderer: Displays the mesh
- Every primitive has both components
- Materials control how mesh looks

SLIDE 6: What are Materials?
-----------------------------
- Materials define surface appearance
- Control: Color, texture, shininess, transparency
- Applied to Mesh Renderer component
- Can be reused across multiple objects
- Stored as .mat files in Project

SLIDE 7: Universal Render Pipeline Materials
---------------------------------------------
- URP uses different shaders than Built-in
- Lit shader: Standard material with lighting
- Unlit shader: No lighting calculations (flat color)
- Properties: Base Map, Base Color, Metallic, Smoothness
- More efficient than Built-in materials

SLIDE 8: Creating a Material
-----------------------------
Steps:
1. Right-click in Project window
2. Create > Material
3. Name it descriptively
4. Select shader (URP/Lit)
5. Adjust properties in Inspector
6. Drag onto object to apply

SLIDE 9: Material Properties - Base Color
------------------------------------------
- Base Color: Main color of the material
- Click color box to open Color Picker
- RGB values: Red, Green, Blue (0-255)
- Alpha: Transparency (0-255)
- Hex color codes also supported

SLIDE 10: Material Properties - Metallic & Smoothness
------------------------------------------------------
- Metallic: How metal-like the surface is (0-1)
  * 0 = Non-metallic (wood, plastic)
  * 1 = Fully metallic (chrome, gold)
- Smoothness: How shiny/rough the surface is (0-1)
  * 0 = Rough (concrete, fabric)
  * 1 = Smooth (mirror, polished metal)

SLIDE 11: Textures vs Colors
-----------------------------
- Solid Color: Single uniform color
- Texture: Image file mapped onto surface
- Base Map: Texture slot in URP materials
- Common formats: PNG, JPG, TGA
- Textures add detail without geometry

SLIDE 12: Project Organization
-------------------------------
Folder structure:
- Materials/ - All material files
- Scripts/ - All C# scripts
- Prefabs/ - Reusable objects
- Scenes/ - Game levels
- Textures/ - Image files
- Audio/ - Sound files

SLIDE 14: Tags in Unity
------------------------
- Tags identify GameObjects for code
- Built-in tags: MainCamera, Player, Finish, etc.
- Create custom tags: Inspector > Tag dropdown
- We'll tag our ground as "Ground"
- Used for collision detection later

SLIDE 15: Understanding Layers
-------------------------------
- Layers control rendering and physics
- Different from tags
- Used for: Camera culling, raycasting, lighting
- Default layers: Default, UI, Water, etc.
- Can create up to 32 layers

SLIDE 16: Color Theory for Games
---------------------------------
- Complementary colors create contrast
- Warm colors (red, orange) = energy, danger
- Cool colors (blue, green) = calm, safe
- Use color to guide player attention
- Our bricks: Warm colors (destructible)
- Our ground: Cool/neutral (stable)

SLIDE 17: Common Material Issues
---------------------------------
- Pink material = Shader error
- Black material = No lighting
- Invisible object = Transparent material
- Wrong shader = URP vs Built-in mismatch
- Always check: Shader type and lighting

SLIDE 18: Performance Considerations
-------------------------------------
- Fewer materials = Better performance
- Reuse materials when possible
- Texture size matters (1024x1024 vs 4096x4096)
- Simple shaders run faster
- Mobile: Keep textures small
