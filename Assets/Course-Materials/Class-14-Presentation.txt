SLIDE 4: Particle System Components
------------------------------------
Main Module:
- Duration: How long it plays
- Looping: Repeat or one-shot
- Start Lifetime: How long particles live
- Start Speed: Initial velocity
- Start Size: Particle size
- Start Color: Particle color

SLIDE 5: Emission Module
-------------------------
- Rate over Time: Particles per second
- Rate over Distance: Particles per unit moved
- Bursts: Sudden particle spawns
- Example: Explosion = Single burst

SLIDE 6: Shape Module
----------------------
- Defines spawn area
- Shapes: Sphere, Box, Cone, Circle
- Angle: Spread of particles
- Radius: Size of spawn area
- Example: Explosion = Sphere

SLIDE 7: Color over Lifetime
-----------------------------
- Change particle color over time
- Gradient editor
- Alpha for fade in/out
- Example: Fire (yellow → orange → red → transparent)

SLIDE 8: Size over Lifetime
----------------------------
- Change particle size over time
- Curve editor
- Example: Smoke (small → large)
- Example: Sparkle (large → small)

SLIDE 9: Velocity over Lifetime
--------------------------------
- Modify particle speed over time
- Orbital velocity
- Radial velocity
- Example: Explosion (fast → slow)

SLIDE 10: Creating a Simple Effect
-----------------------------------
Steps:
1. GameObject > Effects > Particle System
2. Adjust Main module (duration, lifetime)
3. Set Emission (rate or burst)
4. Configure Shape (sphere, cone)
5. Add Color over Lifetime
6. Add Size over Lifetime
7. Test and iterate

SLIDE 13: Auto-Destroy Particles
---------------------------------
- Destroy after effect finishes
- Check "Stop Action: Destroy"
- Or use script:

```csharp
public class AutoDestroy : MonoBehaviour
{
    void Start()
    {
        ParticleSystem ps = GetComponent<ParticleSystem>();
        Destroy(gameObject, ps.main.duration + ps.main.startLifetime.constantMax);
    }
}
```

SLIDE 16: Ground Impact Effect
-------------------------------
```csharp
public GameObject groundEffectPrefab;

void OnCollisionEnter(Collision collision)
{
    if (collision.gameObject.CompareTag("Ground"))
    {
        Vector3 contactPoint = collision.contacts[0].point;
        Instantiate(groundEffectPrefab, contactPoint, Quaternion.identity);
    }
}
```

SLIDE 17: Material Effects - Cracks
------------------------------------
- Texture overlays on material
- Shader shows crack texture
- Alpha blending
- Random offset for variety

```csharp
public Texture2D[] crackTextures;
private Material brickMaterial;

void ShowCracks()
{
    int randomIndex = Random.Range(0, crackTextures.Length);
    brickMaterial.SetTexture("_CrackTexture", crackTextures[randomIndex]);
    brickMaterial.SetFloat("_CrackAlpha", 1f);
}
```

SLIDE 19: Random Texture Offset
--------------------------------
- Prevents identical cracks
- Shifts UV coordinates
- More variety with fewer textures

```csharp
void ApplyCrack()
{
    float offsetX = Random.Range(0f, 1f);
    float offsetY = Random.Range(0f, 1f);
    brickMaterial.SetVector("_Offset", new Vector2(offsetX, offsetY));
}
```

SLIDE 22: Camera Shake
-----------------------
- Adds impact to actions
- Small random movement
- Returns to original position
- Don't overuse!

```csharp
IEnumerator CameraShake(float duration, float magnitude)
{
    Vector3 originalPos = transform.localPosition;
    float elapsed = 0f;
    
    while (elapsed < duration)
    {
        float x = Random.Range(-1f, 1f) * magnitude;
        float y = Random.Range(-1f, 1f) * magnitude;
        
        transform.localPosition = originalPos + new Vector3(x, y, 0);
        
        elapsed += Time.deltaTime;
        yield return null;
    }
    
    transform.localPosition = originalPos;
}
```

SLIDE 23: Screen Flash
-----------------------
- UI Image that flashes
- White or colored overlay
- Fade in/out quickly
- Emphasizes big moments

```csharp
IEnumerator ScreenFlash(Image flashImage, float duration)
{
    flashImage.color = new Color(1, 1, 1, 0.8f);
    
    float elapsed = 0f;
    while (elapsed < duration)
    {
        elapsed += Time.deltaTime;
        float alpha = Mathf.Lerp(0.8f, 0f, elapsed / duration);
        flashImage.color = new Color(1, 1, 1, alpha);
        yield return null;
    }
    
    flashImage.color = new Color(1, 1, 1, 0f);
}
```

SLIDE 26: Performance Considerations
-------------------------------------
- Limit active particle systems
- Use simple particles
- Reduce max particles
- Disable shadows on particles
- Use GPU instancing
- Object pooling for frequent effects
- LOD for distant effects

SLIDE 27: Particle System Optimization
---------------------------------------
```csharp
// In particle system settings:
Max Particles: 50 (not 1000)
Simulation Space: Local (if possible)
Prewarm: Off (unless looping)
Culling Mode: Pause (stop when off-screen)
Rendering Mode: Billboard (simplest)
Cast Shadows: Off
Receive Shadows: Off
```

SLIDE 31: Common Effect Issues
-------------------------------
- Too many particles: Reduce max particles
- Effect doesn't show: Check sorting, position
- Doesn't destroy: Add auto-destroy script
- Performance drop: Optimize particle count
- Wrong color: Check material, lighting
- Clips through objects: Adjust collision
