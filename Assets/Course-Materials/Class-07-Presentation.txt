SLIDE 8: What is Raycasting?
-----------------------------
- Ray: Invisible line in 3D space
- Cast from point in direction
- Detects what it hits
- Returns: Hit object, point, distance
- Essential for: Shooting, clicking, line of sight

SLIDE 9: Ray Components
------------------------
- Origin: Starting point (Vector3)
- Direction: Which way it goes (Vector3)
- Length: How far it travels (float)
- LayerMask: What layers to hit (optional)

```csharp
Ray ray = new Ray(origin, direction);
```

SLIDE 10: Camera.ScreenPointToRay
----------------------------------
- Converts screen position to world ray
- From camera through screen point
- Perfect for mouse clicks

```csharp
Ray ray = Camera.main.ScreenPointToRay(Input.mousePosition);
```

SLIDE 11: Physics.Raycast
--------------------------
- Performs the raycast
- Returns true if hit something
- Outputs hit information

```csharp
if (Physics.Raycast(ray, out RaycastHit hit))
{
    Debug.Log("Hit: " + hit.collider.name);
    Vector3 hitPoint = hit.point;
}
```

SLIDE 12: RaycastHit Information
---------------------------------
```csharp
RaycastHit hit;
if (Physics.Raycast(ray, out hit))
{
    GameObject hitObject = hit.collider.gameObject;
    Vector3 hitPoint = hit.point;
    Vector3 hitNormal = hit.normal;
    float distance = hit.distance;
    Transform hitTransform = hit.transform;
}
```

SLIDE 13: Raycast with Distance
--------------------------------
- Limit ray length
- More efficient
- Prevents hitting distant objects

```csharp
float maxDistance = 100f;
if (Physics.Raycast(ray, out hit, maxDistance))
{
    // Hit something within 100 units
}
```

SLIDE 14: Raycast with LayerMask
---------------------------------
- Only hit specific layers
- Optimization technique
- Ignore certain objects

```csharp
LayerMask mask = LayerMask.GetMask("Brick");
if (Physics.Raycast(ray, out hit, Mathf.Infinity, mask))
{
    // Only hits objects on "Brick" layer
}
```

SLIDE 15: Interface Pattern
----------------------------
- Interface: Contract for classes
- Defines methods classes must implement
- Allows polymorphism
- Clean, flexible code

```csharp
public interface IClickable
{
    void OnClicked(Vector3 point);
}
```

SLIDE 16: Implementing Interfaces
----------------------------------
```csharp
public class Brick : MonoBehaviour, IClickable
{
    public void OnClicked(Vector3 point)
    {
        Debug.Log("Brick clicked at: " + point);
        // Handle click logic
    }
}
```

SLIDE 17: Using Interfaces with Raycasting
-------------------------------------------
```csharp
if (Physics.Raycast(ray, out hit))
{
    IClickable clickable = hit.collider.GetComponent<IClickable>();
    if (clickable != null)
    {
        clickable.OnClicked(hit.point);
    }
}
```

Benefits: Works with any clickable object!

SLIDE 24: Common Raycast Issues
--------------------------------
- No hit: Wrong layer, too short, wrong direction
- Wrong object hit: Layer mask, collider issues
- Multiple hits: Use RaycastAll or order
- Performance: Cache camera, limit distance
- Null reference: Check hit.collider exists

SLIDE 25: Raycast Variations
-----------------------------
- Raycast: Single hit
- RaycastAll: All hits along ray
- RaycastNonAlloc: Performance version
- SphereCast: Thick ray (sphere)
- BoxCast: Box-shaped ray
- CapsuleCast: Capsule-shaped ray

SLIDE 26: Input Delays
-----------------------
- Prevent rapid clicking
- Cooldown between inputs
- Improves game feel
- Prevents spam

```csharp
private float lastClickTime;
private float clickDelay = 0.2f;

if (Time.time - lastClickTime > clickDelay)
{
    // Process click
    lastClickTime = Time.time;
}
```
