SLIDE 3: What are Coroutines?
------------------------------
- Functions that can pause execution
- Resume on next frame or after delay
- Perfect for timing and sequences
- Use yield return statements
- Must return IEnumerator

SLIDE 4: Coroutine Syntax
--------------------------
```csharp
IEnumerator MyCoroutine()
{
    Debug.Log("Start");
    
    yield return new WaitForSeconds(2f);
    
    Debug.Log("2 seconds later");
    
    yield return new WaitForSeconds(1f);
    
    Debug.Log("1 more second later");
}
```

SLIDE 5: Starting Coroutines
-----------------------------
```csharp
// Start a coroutine
StartCoroutine(MyCoroutine());

// Store reference
Coroutine myCoroutine = StartCoroutine(MyCoroutine());

// Start with string (not recommended)
StartCoroutine("MyCoroutine");
```

SLIDE 6: Yield Return Options
------------------------------
```csharp
yield return null;                     // Wait one frame
yield return new WaitForSeconds(2f);   // Wait 2 seconds
yield return new WaitForEndOfFrame();  // End of frame
yield return new WaitForFixedUpdate(); // After physics
yield return StartCoroutine(Other());  // Wait for coroutine
yield break;                           // Exit coroutine
```

SLIDE 7: WaitForSeconds
------------------------
Most common yield:
```csharp
IEnumerator DelayedAction()
{
    Debug.Log("Starting...");
    
    yield return new WaitForSeconds(3f);
    
    Debug.Log("3 seconds passed!");
    DoSomething();
}
```

Affected by Time.timeScale!

SLIDE 8: WaitForSecondsRealtime
--------------------------------
Ignores timeScale (for paused UI):
```csharp
IEnumerator PauseMenuAnimation()
{
    // Works even when Time.timeScale = 0
    yield return new WaitForSecondsRealtime(0.5f);
    
    ShowNextElement();
}
```

SLIDE 9: Timer Coroutine
-------------------------
```csharp
private int remainingTime;

IEnumerator TimerCoroutine(int seconds)
{
    remainingTime = seconds;
    
    while (remainingTime > 0)
    {
        UpdateTimerUI(remainingTime);
        
        yield return new WaitForSeconds(1f);
        
        remainingTime--;
    }
    
    // Time's up!
    OnTimerComplete();
}
```

SLIDE 10: Starting the Timer
-----------------------------
```csharp
public void StartGame(int timeInSeconds)
{
    // Reset state
    score = 0;
    
    // Start timer
    StartCoroutine(TimerCoroutine(timeInSeconds));
    
    // Start gameplay
    wallManager.StartGame();
}

void OnTimerComplete()
{
    EndGame();
}
```

SLIDE 11: Stopping Coroutines
------------------------------
```csharp
private Coroutine timerCoroutine;

public void StartTimer(int seconds)
{
    // Stop existing timer
    if (timerCoroutine != null)
    {
        StopCoroutine(timerCoroutine);
    }
    
    // Start new timer
    timerCoroutine = StartCoroutine(TimerCoroutine(seconds));
}

public void StopTimer()
{
    if (timerCoroutine != null)
    {
        StopCoroutine(timerCoroutine);
        timerCoroutine = null;
    }
}
```

SLIDE 12: StopAllCoroutines
----------------------------
```csharp
void OnDisable()
{
    // Stop all coroutines on this object
    StopAllCoroutines();
}

void EndGame()
{
    StopAllCoroutines();
    // ... end game logic
}
```

Warning: Stops ALL coroutines on this MonoBehaviour!

```csharp
IEnumerator SpawnEnemies()
```

SLIDE 14: Coroutine with Condition
-----------------------------------
```csharp
IEnumerator WaitForCondition()
{
    Debug.Log("Waiting for player to be ready...");
    
    // Wait until condition is true
    yield return new WaitUntil(() => playerReady);
    
    Debug.Log("Player is ready!");
    StartGame();
}

// Also available:
yield return new WaitWhile(() => isLoading);
```

SLIDE 16: Complete Timer System
--------------------------------
```csharp
public class GameManager : MonoBehaviour
{
    private Coroutine timerCoroutine;
    private int remainingTime;
    
    public event Action<int> OnTimerUpdated;
    
    public void StartGame(int seconds)
    {
        remainingTime = seconds;
        timerCoroutine = StartCoroutine(TimerCoroutine());
    }
    
    IEnumerator TimerCoroutine()
    {
        while (remainingTime > 0)
        {
            OnTimerUpdated?.Invoke(remainingTime);
            yield return new WaitForSeconds(1f);
            remainingTime--;
        }
        
        OnTimerUpdated?.Invoke(0);
        EndGame();
    }
    
    void EndGame()
    {
        if (timerCoroutine != null)
        {
            StopCoroutine(timerCoroutine);
        }
        // ... end game
    }
}
```

SLIDE 17: Formatting Time
--------------------------
```csharp
string FormatTime(int totalSeconds)
{
    int minutes = totalSeconds / 60;
    int seconds = totalSeconds % 60;
    
    return $"{minutes:00}:{seconds:00}";
}

// Examples:
// 65 seconds → "01:05"
// 130 seconds → "02:10"
// 45 seconds → "00:45"
```

SLIDE 18: Pause-Aware Timer
----------------------------
```csharp
IEnumerator TimerCoroutine()
{
    while (remainingTime > 0)
    {
        // Skip if paused
        if (currentState == GameState.Paused)
        {
            yield return null;
            continue;
        }
        
        OnTimerUpdated?.Invoke(remainingTime);
        yield return new WaitForSeconds(1f);
        remainingTime--;
    }
    
    EndGame();
}
```

SLIDE 19: Alternative: Time.deltaTime
--------------------------------------
```csharp
private float remainingTime;

void Update()
{
    if (currentState != GameState.Playing) return;
    
    remainingTime -= Time.deltaTime;
    
    if (remainingTime <= 0)
    {
        remainingTime = 0;
        EndGame();
    }
    
    UpdateTimerUI(remainingTime);
}
```

More precise but runs every frame.

SLIDE 20: Sequence Coroutines

```csharp
IEnumerator GameStartSequence()

```

SLIDE 21: Coroutine Best Practices
-----------------------------------
- Store reference if need to stop
- Stop in OnDisable
- Don't use string overload
- Handle pause states
- Keep coroutines focused
- Avoid too many running at once

SLIDE 22: Common Coroutine Mistakes
------------------------------------
- Forgetting to start coroutine
- Not stopping when object destroyed
- Using while(true) without yield
- Forgetting yield return
- Wrong WaitForSeconds value
- Not handling pause
