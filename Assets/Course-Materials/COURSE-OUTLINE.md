## Skills Progression

### By End of Part 1 (Class 6)
- Navigate Unity Editor confidently
- Create and organize projects
- Work with GameObjects and Transforms
- Create materials and prefabs
- Write basic C# scripts

### By End of Part 2 (Class 11)
- Implement physics-based gameplay
- Handle user input
- Use raycasting for interaction
- Apply forces to objects

### By End of Part 3 / Midterm (Class 16)
- Generate procedural content
- Use event-driven architecture
- Manage game state
- Implement timing systems
- **Complete core game loop**

### By End of Part 4 / Final (Class 24)
- Create complete UI systems
- Integrate audio
- Add visual effects
- Animate with DOTween
- Optimize performance
- **Build and publish game**
