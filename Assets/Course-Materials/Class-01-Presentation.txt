CLASS 1: UNITY BASICS & PROJECT SETUP
=====================================

SLIDE 1: Welcome to Unity Game Development
-------------------------------------------
- Course Overview: Building a 3D Wall Breaking Game
- 15 classes from beginner to intermediate
- Hands-on learning approach
- By the end: Complete working game

SLIDE 2: What is Unity?
------------------------
- Game engine for creating 2D and 3D games
- Cross-platform development
- Used by indie developers and AAA studios
- Free for students and small projects
- C# programming language

SLIDE 3: Unity Interface Overview
----------------------------------
- Scene View: Where you build your game world
- Game View: What players will see
- Hierarchy: List of all objects in current scene
- Project: All assets and files in your project
- Inspector: Properties of selected object
- Console: Error messages and debug logs

SLIDE 4: Understanding GameObjects
-----------------------------------
- Everything in Unity is a GameObject
- GameObjects are containers for Components
- Components add functionality (Transform, Renderer, etc.)
- Transform component: Position, Rotation, Scale
- Every GameObject has a Transform

SLIDE 5: The Transform Component
---------------------------------
- Position: X, Y, Z coordinates in 3D space
- Rotation: X, Y, Z angles in degrees
- Scale: X, Y, Z size multipliers
- Local vs World space
- Parent-child relationships affect transforms

SLIDE 6: Creating Your First Scene
-----------------------------------
- Scene = Level or menu in your game
- Every scene needs a Camera (what player sees)
- Directional Light for illumination
- Creating objects: Right-click in Hierarchy
- Saving scenes: File > Save Scene

SLIDE 7: The Camera
-------------------
- Camera component defines what player sees
- Main Camera tag: Primary camera in scene
- Projection: Perspective (3D) vs Orthographic (2D)
- Field of View (FOV): How wide the view is
- Clipping Planes: Near and Far render distances

SLIDE 8: Lighting Basics
-------------------------
- Directional Light: Like the sun, affects everything
- Point Light: Like a light bulb, radiates in all directions
- Spot Light: Like a flashlight, cone of light
- Light properties: Color, Intensity, Shadows
- Ambient lighting: Overall scene brightness

SLIDE 9: Navigation in Unity
-----------------------------
- Scene View Navigation:
  * Right-click + WASD: Fly camera
  * Alt + Left-click: Orbit around object
  * Alt + Right-click: Zoom
  * Middle-mouse: Pan
  * F key: Focus on selected object
  * Q, W, E, R, T: Tool shortcuts

SLIDE 10: Project Setup - Universal Render Pipeline (URP)
----------------------------------------------------------
- URP: Modern, optimized rendering
- Better performance than Built-in pipeline
- Better graphics with less effort
- Mobile-friendly
- Industry standard for modern Unity projects

SLIDE 12: Best Practices
-------------------------
- Save your work frequently (Ctrl+S)
- Organize your project folders
- Use meaningful names for objects
- Keep scenes clean and organized
- Test often in Game view

SLIDE 13: Common Beginner Mistakes
-----------------------------------
- Not saving the scene
- Forgetting to save the project
- Deleting the Main Camera
- Not organizing assets
- Working in Game view instead of Scene view

SLIDE 14: Homework/Practice
