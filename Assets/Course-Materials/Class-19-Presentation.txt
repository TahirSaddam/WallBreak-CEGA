SLIDE 2: Why Audio Matters
---------------------------
Audio provides:
- Feedback (hit sounds)
- Atmosphere (music)
- Immersion
- Emotional impact
- Information (warnings)

Games without audio feel empty!

SLIDE 3: Audio Components
--------------------------
AudioListener:
- "Ears" of the game
- Usually on Main Camera
- Only ONE in scene

AudioSource:
- Plays audio clips
- Multiple per scene
- Attach to GameObjects

AudioClip:
- The actual sound file
- Import audio files

SLIDE 4: AudioListener
-----------------------
- Receives all audio
- Attached to Main Camera (default)
- Position affects 3D sound
- Only one active at a time

Check: Main Camera has AudioListener!

SLIDE 5: AudioSource Component
-------------------------------
Key properties:
- AudioClip: Sound to play
- Output: Audio Mixer (optional)
- Mute: Silence
- Play On Awake: Auto-play
- Loop: Repeat
- Volume: 0-1
- Pitch: Speed/tone
- Spatial Blend: 2D vs 3D

SLIDE 6: 2D vs 3D Audio
------------------------
2D Audio (Spatial Blend = 0):
- Same volume everywhere
- Good for: Music, UI sounds

3D Audio (Spatial Blend = 1):
- Volume based on distance
- Directional
- Good for: World sounds, footsteps

SLIDE 7: Playing Audio
-----------------------
```csharp
AudioSource audioSource;

void Start()
{
    audioSource = GetComponent<AudioSource>();
}

// Play assigned clip
audioSource.Play();

// Play specific clip
audioSource.PlayOneShot(clipToPlay);

// Play at position (3D)
AudioSource.PlayClipAtPoint(clip, position);
```

SLIDE 8: Play vs PlayOneShot
-----------------------------
Play():
- Plays AudioSource's clip
- Stops current sound
- Use for: Music, looping

PlayOneShot(clip):
- Plays clip once
- Overlaps with current
- Use for: Sound effects

SLIDE 9: Audio File Formats
----------------------------
Supported:
- .mp3 - Compressed, common
- .wav - Uncompressed, high quality
- .ogg - Compressed, good quality
- .aiff - Uncompressed

Recommendations:
- Music: .mp3 or .ogg
- SFX: .wav for short sounds

SLIDE 10: Import Settings
--------------------------
Select audio file in Project:
- Load Type: Decompress on Load (small), Streaming (large)
- Compression Format: Vorbis (quality), ADPCM (performance)
- Sample Rate: Usually Auto
- Force To Mono: For 3D sounds

SLIDE 11: SoundManager Singleton
---------------------------------
```csharp
public class SoundManager : MonoBehaviour
{
    public static SoundManager Instance { get; private set; }
    
    [Header("Audio Sources")]
    [SerializeField] private AudioSource musicSource;
    [SerializeField] private AudioSource sfxSource;
    
    [Header("Music Clips")]
    [SerializeField] private AudioClip menuMusic;
    [SerializeField] private AudioClip gameplayMusic;
    
    [Header("SFX Clips")]
    [SerializeField] private AudioClip brickHitSound;
    [SerializeField] private AudioClip buttonClickSound;
    [SerializeField] private AudioClip gameOverSound;
    
    void Awake()
    {
        if (Instance == null)
        {
            Instance = this;
            DontDestroyOnLoad(gameObject);
        }
        else
        {
            Destroy(gameObject);
        }
    }
}
```

SLIDE 14: Volume Control
-------------------------
```csharp
[Range(0f, 1f)]
[SerializeField] private float musicVolume = 0.5f;

[Range(0f, 1f)]
[SerializeField] private float sfxVolume = 1f;

public void SetMusicVolume(float volume)
{
    musicVolume = volume;
    musicSource.volume = musicVolume;
}

public void SetSFXVolume(float volume)
{
    sfxVolume = volume;
    sfxSource.volume = sfxVolume;
}
```

SLIDE 15: Playing Sound on Events
----------------------------------
```csharp
void OnEnable()
{
    Brick3D.OnAnyBrickDetached += OnBrickHit;
}

void OnDisable()
{
    Brick3D.OnAnyBrickDetached -= OnBrickHit;
}

void OnBrickHit(Brick3D brick)
{
    PlayBrickHit();
}
```

SLIDE 16: Random Sound Variation
---------------------------------
```csharp
[SerializeField] private AudioClip[] brickHitSounds;

public void PlayBrickHit()
{
    if (brickHitSounds.Length > 0)
    {
        int index = Random.Range(0, brickHitSounds.Length);
        sfxSource.PlayOneShot(brickHitSounds[index]);
    }
}
```

Variety prevents repetition fatigue!

SLIDE 17: Pitch Variation
--------------------------
```csharp
public void PlayBrickHitWithVariation()
{
    // Random pitch between 0.9 and 1.1
    sfxSource.pitch = Random.Range(0.9f, 1.1f);
    sfxSource.PlayOneShot(brickHitSound);
    sfxSource.pitch = 1f;  // Reset
}
```

Subtle variation feels natural!

SLIDE 22: Common Audio Issues
------------------------------
No sound:
- Check AudioListener exists
- Check AudioSource volume
- Check clip is assigned
- Check mute is off

Sound too loud/quiet:
- Adjust volume
- Check import settings

SLIDE 23: Audio Best Practices
-------------------------------
- Keep music and SFX separate
- Use PlayOneShot for SFX
- Add variation (pitch, multiple clips)
- Don't spam sounds
- Balance volumes
- Test with headphones
