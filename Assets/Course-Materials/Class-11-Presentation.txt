SLIDE 2: What is a Game Manager?
---------------------------------
- Central controller for game
- Manages game state
- Coordinates systems
- Handles game flow
- Typically a singleton
- One per scene

SLIDE 3: Game States
---------------------
Common states:
- MainMenu: Title screen
- Playing: Active gameplay
- Paused: Game frozen
- GameOver: End screen
- Loading: Between scenes

Our game states:
- Menu, TimeSelect, Playing, GameOver

SLIDE 4: State Management
--------------------------
- Track current state
- Transition between states
- State-specific logic
- Prevent invalid transitions

```csharp
public enum GameState
{
    Menu,
    Playing,
    Paused,
    GameOver
}

private GameState currentState;
```

SLIDE 5: The Singleton Pattern
-------------------------------
- Design pattern for single instance
- Global access point
- Persists across scenes (optional)
- Common for managers

Benefits:
- Easy access from anywhere
- Guaranteed single instance
- No need to find/reference

SLIDE 6: Implementing Singleton
--------------------------------
```csharp
public class GameManager : MonoBehaviour
{
    public static GameManager instance;
    
    void Awake()
    {
        if (instance == null)
        {
            instance = this;
            DontDestroyOnLoad(gameObject);
        }
        else
        {
            Destroy(gameObject);
        }
    }
}
```

SLIDE 7: DontDestroyOnLoad
---------------------------
- Persists object between scenes
- Survives scene loading
- Useful for managers, music, etc.
- Be careful: Can cause duplicates

```csharp
DontDestroyOnLoad(gameObject);
```

SLIDE 8: Accessing Singleton
-----------------------------

SLIDE 11: Timer System
-----------------------
- Count down or count up
- Display remaining time
- End game when time expires
- Use Coroutines for timing

```csharp
private int remainingTime;

public void StartTimer(int seconds)
{
    remainingTime = seconds;
    StartCoroutine(TimerCoroutine());
}
```

SLIDE 12: What are Coroutines?
-------------------------------
- Functions that can pause execution
- Resume on next frame or after delay
- Perfect for timing and sequences
- Use yield return statements
- Must return IEnumerator

SLIDE 13: Coroutine Basics
---------------------------
```csharp
IEnumerator MyCoroutine()
{
    Debug.Log("Start");
    
    yield return new WaitForSeconds(2f);
    
    Debug.Log("2 seconds later");
    
    yield return null;  // Wait one frame
    
    Debug.Log("Next frame");
}

// Start it
StartCoroutine(MyCoroutine());
```

SLIDE 14: Timer Coroutine
--------------------------
```csharp
IEnumerator TimerCoroutine()
{
    while (remainingTime > 0)
    {
        uiManager.SetTimerText(remainingTime);
        remainingTime--;
        yield return new WaitForSeconds(1f);
    }
    
    // Time's up
    EndGame();
}
```

SLIDE 15: Stopping Coroutines
------------------------------
```csharp
// Store reference
Coroutine timerCoroutine;

// Start
timerCoroutine = StartCoroutine(TimerCoroutine());

// Stop
if (timerCoroutine != null)
{
    StopCoroutine(timerCoroutine);
}

// Stop all
StopAllCoroutines();
```

SLIDE 16: Game Flow
--------------------
1. Main Menu
   ↓
2. Time Selection
   ↓
3. Start Game
   ↓
4. Play (spawn walls, timer)
   ↓
5. Time expires
   ↓
6. Game Over screen
   ↓
7. Play Again or Quit

SLIDE 17: Starting the Game
----------------------------
```csharp
public void StartGame(int timeInSeconds)
{
    // Reset score
    score = 0;
    uiManager.SetScoreText(score);
    
    // Start timer
    remainingTime = timeInSeconds;
    StartCoroutine(TimerCoroutine());
    
    // Spawn first wall
    wallManager.SpawnNewWall();
    
    // Start music
    SoundManager.instance.PlayGameplayMusic();
}
```

SLIDE 18: Ending the Game
--------------------------
```csharp
void EndGame()
{
    // Stop gameplay
    wallManager.GameOver();
    
    // Stop music, play game over sound
    SoundManager.instance.PlayGameOverMusic();
    
    // Show end screen with score
    uiManager.ShowEndScreen(score);
    
    // Could save high score here
}
```

SLIDE 23: Coroutine Yield Options
----------------------------------
```csharp
yield return null;                    // Next frame
yield return new WaitForSeconds(2f);  // After 2 seconds
yield return new WaitForEndOfFrame(); // End of frame
yield return new WaitForFixedUpdate();// After physics
yield return StartCoroutine(Other()); // Wait for coroutine
yield break;                          // Exit coroutine
```

SLIDE 24: Time.timeScale
-------------------------
- Controls game speed
- 1 = Normal speed
- 0 = Paused
- 0.5 = Half speed
- 2 = Double speed

```csharp
void PauseGame()
{
    Time.timeScale = 0f;
}

void ResumeGame()
{
    Time.timeScale = 1f;
}
```

SLIDE 25: Common Manager Mistakes
----------------------------------
1. Multiple singletons
   - Check before creating

2. Not destroying duplicates
   - Destroy in Awake

3. Forgetting DontDestroyOnLoad
   - Manager destroyed on scene load

4. Too many responsibilities
   - Keep managers focused

5. Tight coupling
   - Use events when possible
