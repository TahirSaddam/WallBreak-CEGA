SLIDE 3: AddForce
------------------
Apply force to Rigidbody:
```csharp
Rigidbody rb = GetComponent<Rigidbody>();

// Apply force
rb.AddForce(Vector3.up * 100f);

// With ForceMode
rb.AddForce(Vector3.forward * 50f, ForceMode.Impulse);
```

SLIDE 4: ForceMode Options
---------------------------
```csharp
ForceMode.Force        // Continuous, uses mass
ForceMode.Impulse      // Instant, uses mass
ForceMode.Acceleration // Continuous, ignores mass
ForceMode.VelocityChange // Instant, ignores mass
```

For our game:
- Impulse = Best for impacts
- Instant force considering mass

SLIDE 5: Force vs Impulse
--------------------------
Force (continuous):
```csharp
// Apply every FixedUpdate
void FixedUpdate()
{
    rb.AddForce(Vector3.forward * 10f, ForceMode.Force);
}
```

Impulse (instant):
```csharp
// Apply once
void OnClicked()
{
    rb.AddForce(Vector3.back * 500f, ForceMode.Impulse);
}
```

SLIDE 6: Calculating Impact Direction
--------------------------------------
```csharp
public void OnClicked(Vector3 impactPoint)
{
    // Direction from impact point to brick center
    Vector3 direction = transform.position - impactPoint;
    direction.Normalize();  // Make length 1
    
    // Apply force in that direction
    rb.AddForce(direction * impactForce, ForceMode.Impulse);
}
```

Brick flies away from click point!

SLIDE 7: AddForceAtPosition
----------------------------

```csharp
// Force applied at impact point
rb.AddForceAtPosition(

);
```

Creates rotation based on where hit!

SLIDE 8: Torque
----------------
Apply rotational force:

Makes bricks tumble realistically!

SLIDE 9: Complete Impact Code
------------------------------
```csharp
public void OnClicked(Vector3 impactPoint)
{
    // Release from wall
    rb.isKinematic = false;
    
    // Calculate direction
    Vector3 direction = (transform.position - impactPoint).normalized;
    
    // Add backward force
    rb.AddForce(direction * impactForce, ForceMode.Impulse);
    
    // Add downward force
    rb.AddForce(Vector3.down * fallForce, ForceMode.Impulse);
    
    // Add random rotation
    Vector3 torque = Random.insideUnitSphere * torqueAmount;
    rb.AddTorque(torque, ForceMode.Impulse);
}
```

SLIDE 11: Impact Radius Effect
-------------------------------
When brick is hit, affect nearby bricks:
```csharp
void ApplyImpactToNearby(Vector3 impactPoint, float radius)
{
    Collider[] nearby = Physics.OverlapSphere(impactPoint, radius);
    
    foreach (Collider col in nearby)
    {
        Brick3D brick = col.GetComponent<Brick3D>();
        if (brick != null && brick != this)
        {
            brick.ReceiveImpact(impactPoint);
        }
    }
}
```

SLIDE 12: ReceiveImpact Method
-------------------------------
```csharp
public void ReceiveImpact(Vector3 sourcePoint)
{
    // Calculate distance for falloff
    float distance = Vector3.Distance(transform.position, sourcePoint);
    float falloff = 1f - (distance / maxRadius);
    falloff = Mathf.Clamp01(falloff);
    
    // Apply reduced force based on distance
    Vector3 direction = (transform.position - sourcePoint).normalized;
    rb.AddForce(direction * impactForce * falloff, ForceMode.Impulse);
}
```

LayerMask brickLayer = LayerMask.GetMask("Brick");

SLIDE 14: Explosion Force (Built-in)
-------------------------------------
Unity has built-in explosion:
```csharp
void CreateExplosion(Vector3 position, float force, float radius)
{
    Collider[] colliders = Physics.OverlapSphere(position, radius);
    
    foreach (Collider col in colliders)
    {
        Rigidbody rb = col.GetComponent<Rigidbody>();
        if (rb != null)
        {
            rb.AddExplosionForce(force, position, radius);
        }
    }
}
```

rb.AddExplosionForce(

SLIDE 18: Complete OnClicked
-----------------------------
```csharp
public void OnClicked(Vector3 impactPoint)
{
    if (isDetached) return;  // Already falling
    
    DetachBrick(impactPoint);
    ApplyImpactToNearby(impactPoint);
}

void DetachBrick(Vector3 impactPoint)
{
    isDetached = true;
    rb.isKinematic = false;
    
    Vector3 direction = (transform.position - impactPoint).normalized;
    
    rb.AddForce(direction * impactForce, ForceMode.Impulse);
    rb.AddForce(Vector3.down * fallForce, ForceMode.Impulse);
    rb.AddTorque(Random.insideUnitSphere * torqueAmount, ForceMode.Impulse);
}
```

SLIDE 19: Nearby Impact Implementation
---------------------------------------
```csharp
void ApplyImpactToNearby(Vector3 impactPoint)
{
    Collider[] nearby = Physics.OverlapSphere(
        transform.position, 
        impactRadius
    );
    
    foreach (Collider col in nearby)
    {
        Brick3D brick = col.GetComponent<Brick3D>();
        if (brick != null && brick != this && !brick.isDetached)
        {
            // Small push, not full detach
            Rigidbody otherRb = brick.GetComponent<Rigidbody>();
            Vector3 pushDir = (brick.transform.position - transform.position).normalized;
            otherRb.AddForce(pushDir * impactForce * 0.3f, ForceMode.Impulse);
        }
    }
}
```

SLIDE 20: Tuning Physics
-------------------------
Good starting values:
- impactForce: 300-500
- fallForce: 200-400
- torqueAmount: 30-70
- impactRadius: 1-2

Tips:
- Test frequently
- Small changes, big differences
- Watch for objects flying too far
- Consider mass of objects

SLIDE 21: Velocity Limits
--------------------------
Prevent objects going too fast:
```csharp
void FixedUpdate()
{
    // Clamp velocity
    if (rb.velocity.magnitude > maxVelocity)
    {
        rb.velocity = rb.velocity.normalized * maxVelocity;
    }
}
```

SLIDE 23: Common Force Mistakes
--------------------------------
- Applying force to kinematic Rigidbody
- Force too strong (objects fly away)
- Force too weak (no visible effect)
- Forgetting ForceMode
- Applying in Update instead of once
- Not normalizing direction
