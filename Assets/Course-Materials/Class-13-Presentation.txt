SLIDE 3: Types of Game Audio
-----------------------------
1. Music:
   - Background music
   - Menu music
   - Victory/defeat music
   - Ambient sounds

2. Sound Effects (SFX):
   - Actions (jump, shoot, hit)
   - UI (button clicks, notifications)
   - Environment (wind, water)
   - Feedback (pickup, damage)

SLIDE 4: AudioClip
-------------------
- Asset that stores audio data
- Supported formats:
  * WAV: Uncompressed, high quality
  * MP3: Compressed, smaller size
  * OGG: Compressed, good quality
- Import: Drag into Project window
- Settings: Compression, quality, 3D sound

SLIDE 5: AudioSource Component
-------------------------------
- Plays AudioClips
- Attached to GameObject
- Properties:
  * Clip: AudioClip to play
  * Volume: 0 to 1
  * Pitch: Speed/tone (0.1 to 3)
  * Loop: Repeat when finished
  * Play On Awake: Auto-play at start

SLIDE 6: AudioListener Component
---------------------------------
- "Ears" of the game
- Usually on Main Camera
- Only one per scene
- Receives sound from AudioSources
- 3D audio based on distance from listener

SLIDE 7: 2D vs 3D Audio
------------------------
2D Audio (Spatial Blend = 0):
- Same volume everywhere
- No position in 3D space
- Use for: Music, UI sounds

3D Audio (Spatial Blend = 1):
- Volume based on distance
- Stereo panning based on position
- Use for: In-game sounds, effects

SLIDE 8: Playing Audio from Code
---------------------------------
```csharp
public class AudioExample : MonoBehaviour
{
    private AudioSource audioSource;
    public AudioClip soundEffect;
    
    void Start()
    {
        audioSource = GetComponent<AudioSource>();
    }
    
    void PlaySound()
    {
        audioSource.Play();  // Play assigned clip
        audioSource.PlayOneShot(soundEffect);  // Play specific clip
    }
}
```

SLIDE 9: Play() vs PlayOneShot()
---------------------------------
Play():
- Stops current sound
- Plays new sound
- One sound at a time
- Use for: Music, long sounds

PlayOneShot():
- Doesn't stop current sound
- Overlaps sounds
- Multiple sounds simultaneously
- Use for: Sound effects

SLIDE 11: SoundManager Pattern
-------------------------------
- Singleton for audio management
- Centralized audio control
- Easy access from anywhere
- Manages music and SFX
- Persists across scenes

Benefits:
- Consistent audio
- Easy to adjust volumes
- Clean code organization

SLIDE 12: SoundManager Structure
---------------------------------
```csharp
public class SoundManager : MonoBehaviour
{
    public static SoundManager instance;
    
    [Header("Music")]
    public AudioClip bgmMusic;
    public AudioClip gameplayMusic;
    public AudioClip gameOverMusic;
    
    [Header("Sound Effects")]
    public AudioClip[] brickHitSounds;
    public AudioClip buttonClick;
    
    private AudioSource audioSource;
    
    void Awake()
    {
        // Singleton setup
        if (instance == null)
        {
            instance = this;
            DontDestroyOnLoad(gameObject);
        }
        else
        {
            Destroy(gameObject);
        }
        
        audioSource = GetComponent<AudioSource>();
    }
}
```

SLIDE 15: Multiple AudioSources
--------------------------------
- One for music (looping)
- One for SFX (one-shots)
- Prevents SFX interrupting music

```csharp
private AudioSource musicSource;
private AudioSource sfxSource;

void Awake()
{
    musicSource = gameObject.AddComponent<AudioSource>();
    sfxSource = gameObject.AddComponent<AudioSource>();
    
    musicSource.loop = true;
}

public void PlayMusic(AudioClip clip)
{
    musicSource.clip = clip;
    musicSource.Play();
}

public void PlaySFX(AudioClip clip)
{
    sfxSource.PlayOneShot(clip);
}
```

SLIDE 17: Audio Import Settings
--------------------------------
In Inspector (AudioClip):
- Load Type:
  * Decompress On Load: Fast, uses RAM
  * Compressed In Memory: Slower, saves RAM
  * Streaming: Large files, minimal RAM
  
- Compression Format:
  * PCM: Uncompressed, high quality
  * Vorbis: Compressed, good quality
  * ADPCM: Low CPU, moderate quality

SLIDE 18: Optimization Tips
----------------------------
Music:
- Use Streaming load type
- Vorbis compression
- Lower quality (128 kbps)
- Mono if possible

SFX:
- Decompress On Load
- Short sounds: PCM
- Long sounds: Vorbis
- Keep file sizes small

SLIDE 23: Fade In/Out
----------------------
```csharp
IEnumerator FadeOut(float duration)
{
    float startVolume = audioSource.volume;
    float elapsed = 0f;
    
    while (elapsed < duration)
    {
        elapsed += Time.deltaTime;
        audioSource.volume = Mathf.Lerp(startVolume, 0f, elapsed / duration);
        yield return null;
    }
    
    audioSource.Stop();
    audioSource.volume = startVolume;
}

// Usage
StartCoroutine(FadeOut(2f));
```

SLIDE 24: Random Pitch Variation
---------------------------------
- Adds variety to repeated sounds
- Prevents monotony
- Sounds more natural

```csharp
public void PlaySFXWithVariation(AudioClip clip)
{
    sfxSource.pitch = Random.Range(0.9f, 1.1f);
    sfxSource.PlayOneShot(clip);
    sfxSource.pitch = 1f;  // Reset
}
```

SLIDE 25: Audio Pooling
------------------------
- For many simultaneous sounds
- Reuse AudioSource components
- Better performance

```csharp
private List<AudioSource> audioPool = new List<AudioSource>();

AudioSource GetAvailableSource()
{
    foreach (AudioSource source in audioPool)
    {
        if (!source.isPlaying)
            return source;
    }
    
    // Create new if none available
    AudioSource newSource = gameObject.AddComponent<AudioSource>();
    audioPool.Add(newSource);
    return newSource;
}
```

SLIDE 26: Common Audio Issues
------------------------------
- No sound: Check AudioListener, volume
- Distorted: Lower volume, check clipping
- Delayed: Use Decompress On Load
- Stuttering: Check CPU usage, compression
- Wrong position: Check 2D/3D settings
- Multiple sounds: Use PlayOneShot
