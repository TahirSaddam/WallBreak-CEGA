SLIDE 7: Common Integration Issues
-----------------------------------
Issue: Nothing happens on click
- Check RayCastManager is in scene
- Check InputAction is enabled
- Check raycast hits collider
- Check IOption is implemented

Issue: Brick doesn't fall
- Check Rigidbody exists
- Check isKinematic toggles
- Check forces are applied

SLIDE 8: Common Integration Issues (2)
---------------------------------------
Issue: Score doesn't update
- Check event subscription
- Check event is invoked
- Check GameManager.Instance exists

Issue: Wall doesn't respawn
- Check WallManager receives events
- Check brick count tracking
- Check GenerateWall is called

SLIDE 25: Final Integration Code (2)
-------------------------------------
WallManager flow:
```csharp
void OnBrickDetached(Brick3D brick)
{
    remainingBricks--;
    
    if (remainingBricks <= 0)
    {
        SpawnNextWall();
    }
}

void SpawnNextWall()
{
    wallGenerator.GenerateWall();
    remainingBricks = wallGenerator.GetBrickCount();
}
```
