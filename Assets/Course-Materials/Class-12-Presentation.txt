SLIDE 2: What is Procedural Generation?
----------------------------------------
- Creating content algorithmically
- Not hand-placed, but generated
- Can create infinite variations
- Used for: Levels, terrain, items, enemies

Our use: Generate brick walls!

SLIDE 3: Why Procedural Generation?
------------------------------------
Benefits:
- Replayability (different each time)
- Less manual work
- Scalable content
- Dynamic difficulty
- Smaller file size

For our game:
- Multiple walls
- Different patterns
- Progressive difficulty

SLIDE 4: Grid-Based Generation
-------------------------------
Our wall is a grid:
- Rows: Vertical count
- Columns: Horizontal count
- Each cell: One brick

```
[B][B][B][B][B]  <- Row 2
[B][B][B][B][B]  <- Row 1
[B][B][B][B][B]  <- Row 0
```

SLIDE 5: Nested Loops
----------------------
Generate grid with nested loops:
```csharp
for (int row = 0; row < rows; row++)
{
    for (int col = 0; col < columns; col++)
    {
        // Create brick at (col, row)
        SpawnBrick(col, row);
    }
}
```

Outer loop: Rows (Y)
Inner loop: Columns (X)

SLIDE 6: Position Calculation
------------------------------
Convert grid position to world position:
```csharp
void SpawnBrick(int col, int row)
{
    float x = col * (brickWidth + spacing);
    float y = row * (brickHeight + spacing);
    float z = 0;
    
    Vector3 position = new Vector3(x, y, z);
    
    Instantiate(brickPrefab, position, Quaternion.identity);
}
```

SLIDE 7: Brick Dimensions
--------------------------
Our brick prefab:
- Scale: (2, 1, 1)
- Width: 2 units
- Height: 1 unit
- Depth: 1 unit

With spacing:
- brickWidth = 2f
- brickHeight = 1f
- spacing = 0.05f (small gap)

SLIDE 8: Centering the Wall
----------------------------
Center wall on X axis:
```csharp
float wallWidth = columns * (brickWidth + spacing);
float offsetX = -wallWidth / 2f + brickWidth / 2f;

Vector3 position = new Vector3(
    col * (brickWidth + spacing) + offsetX,
    row * (brickHeight + spacing),
    0
);
```

SLIDE 9: Parent Organization
-----------------------------
Keep hierarchy clean:
```csharp
public class WallGenerator3D : MonoBehaviour
{
    void GenerateWall()
    {
        // Create parent for this wall
        GameObject wallParent = new GameObject("Wall");
        
        for (int row = 0; row < rows; row++)
        {
            for (int col = 0; col < columns; col++)
            {
                GameObject brick = Instantiate(brickPrefab, position, rotation);
                brick.transform.parent = wallParent.transform;
            }
        }
    }
}
```

SLIDE 12: GenerateWall Method
------------------------------
```csharp
public void GenerateWall()
{
    // Calculate offset to center wall
    float wallWidth = columns * (brickWidth + spacing);
    float offsetX = -wallWidth / 2f + brickWidth / 2f;
    
    // Create parent object
    GameObject wallParent = new GameObject("Wall");
    wallParent.transform.position = transform.position;
    
    // Generate grid
    for (int row = 0; row < rows; row++)
    {
        for (int col = 0; col < columns; col++)
        {
            SpawnBrick(col, row, offsetX, wallParent.transform);
        }
    }
}
```

SLIDE 13: SpawnBrick Method
----------------------------
```csharp
void SpawnBrick(int col, int row, float offsetX, Transform parent)
{
    // Calculate position
    float x = col * (brickWidth + spacing) + offsetX;
    float y = row * (brickHeight + spacing);
    float z = transform.position.z;
    
    Vector3 position = new Vector3(x, y, z);
    
    // Spawn brick
    GameObject brick = Instantiate(
        brickPrefab, 
        position, 
        Quaternion.identity, 
        parent
    );
    
    brick.name = $"Brick_{col}_{row}";
}
```

SLIDE 16: Tracking Bricks
--------------------------
Store references for later:
```csharp
private List<Brick3D> allBricks = new List<Brick3D>();

void SpawnBrick(...)
{
    GameObject brick = Instantiate(...);
    
    Brick3D brickScript = brick.GetComponent<Brick3D>();
    if (brickScript != null)
    {
        allBricks.Add(brickScript);
    }
}

public int GetRemainingBricks()
{
    return allBricks.Count;
}
```

SLIDE 17: Clearing Walls
-------------------------
Remove old wall before new:
```csharp
private GameObject currentWall;

public void GenerateWall()
{
    // Destroy old wall
    if (currentWall != null)
    {
        Destroy(currentWall);
    }
    
    allBricks.Clear();
    
    // Create new wall
    currentWall = new GameObject("Wall");
    // ... rest of generation
}
```

SLIDE 18: Wall Patterns (Preview)
----------------------------------
Different arrangements:
```csharp
bool ShouldSpawnBrick(int col, int row)
{
    // Normal: All bricks
    return true;
    
    // Checkerboard
    return (col + row) % 2 == 0;
    
    // Pyramid
    return col >= (columns - row) / 2 && 
           col < columns - (columns - row) / 2;
}
```

SLIDE 22: Common Mistakes
--------------------------
- Wrong position calculation
- Forgetting offset for centering
- Not parenting bricks
- Prefab not assigned
- Bricks spawning inside each other
- Performance with too many bricks

SLIDE 23: Performance Tips
---------------------------
- Don't spawn too many bricks (100-200 max)
- Use object pooling for respawning
- Disable bricks instead of destroy
- Consider LOD for distant walls
- Profile if slow
