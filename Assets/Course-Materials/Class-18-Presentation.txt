SLIDE 2: What is TextMeshPro?
------------------------------
- Advanced text rendering
- Better quality than legacy Text
- More styling options
- Better performance
- Industry standard
- Free and built into Unity

SLIDE 3: Installing TextMeshPro
--------------------------------
First time setup:
1. Window > TextMeshPro > Import TMP Essential Resources
2. Click Import
3. Creates TextMesh Pro folder
4. Includes fonts and materials

Only need to do once per project!

SLIDE 4: TMP vs Legacy Text
----------------------------
Legacy Text:
- Basic rendering
- Limited styling
- Blurry at large sizes

TextMeshPro:
- Signed Distance Field (SDF)
- Crisp at any size
- Rich text support
- Outlines, shadows, glow

SLIDE 5: Creating TMP Text
---------------------------
In Canvas:
1. Right-click > UI > Text - TextMeshPro
2. First time: Import TMP Essentials
3. Configure in Inspector

Or via code:
```csharp
using TMPro;
TMP_Text myText;
```

SLIDE 6: TMP_Text Properties
-----------------------------
Key properties:
- Text: The string to display
- Font Asset: Which font
- Font Size: Text size
- Color: Text color
- Alignment: Left, center, right
- Overflow: How to handle long text

SLIDE 7: Font Styling
----------------------
```
Font Style:
```

Combine styles!

SLIDE 8: Rich Text Tags
------------------------
Inline formatting:
```
<b>Bold</b>
<i>Italic</i>
<size=24>Size</size>
<color=red>Red</color>
<color=#FF0000>Hex color</color>
Score: <b>{score}</b>
```

Enable "Rich Text" in Inspector!

SLIDE 9: TMP_Text in Code
--------------------------
```csharp
using TMPro;

public class UIManager : MonoBehaviour
{
    [SerializeField] private TMP_Text scoreText;
    [SerializeField] private TMP_Text timerText;
    
    public void UpdateScore(int score)
    {
        scoreText.text = $"Score: {score}";
    }
    
    public void UpdateTimer(int seconds)
    {
        int min = seconds / 60;
        int sec = seconds % 60;
        timerText.text = $"{min:00}:{sec:00}";
    }
}
```

SLIDE 10: Button Component

SLIDE 11: Button Transitions

Color Tint (most common):

SLIDE 12: Button OnClick Event
-------------------------------

1. Find On Click () section

3. Drag GameObject with script

Methods must be public!

SLIDE 13: Button in Code
-------------------------
```csharp
using UnityEngine.UI;

public class UIManager : MonoBehaviour
{
    [SerializeField] private Button playButton;
    
    void Start()
    {
        playButton.onClick.AddListener(OnPlayClicked);
    }
    
    void OnPlayClicked()
    {
        Debug.Log("Play clicked!");
        GameManager.Instance.StartGame(60);
    }
    
    void OnDestroy()
    {
        playButton.onClick.RemoveListener(OnPlayClicked);
    }
}
```

SLIDE 14: Panel Management

SLIDE 15: UIManager Structure
------------------------------
```csharp
public class UIManager : MonoBehaviour
{
    [Header("Panels")]
    [SerializeField] private GameObject mainMenuPanel;
    [SerializeField] private GameObject timeSelectPanel;
    [SerializeField] private GameObject gameplayPanel;
    [SerializeField] private GameObject pausePanel;
    [SerializeField] private GameObject gameOverPanel;
    
    [Header("Gameplay UI")]
    [SerializeField] private TMP_Text scoreText;
    [SerializeField] private TMP_Text timerText;
    
    [Header("Game Over UI")]
    [SerializeField] private TMP_Text finalScoreText;

```

SLIDE 16: UIManager Methods
----------------------------
```csharp
public void ShowMainMenu()
{
    HideAllPanels();
    mainMenuPanel.SetActive(true);
}

public void ShowGameplay()
{
    HideAllPanels();
    gameplayPanel.SetActive(true);
}

public void ShowGameOver(int finalScore)
{
    HideAllPanels();
    gameOverPanel.SetActive(true);
    finalScoreText.text = $"Final Score: {finalScore}";
}

void HideAllPanels()
{
    mainMenuPanel.SetActive(false);
    timeSelectPanel.SetActive(false);
    gameplayPanel.SetActive(false);
    pausePanel.SetActive(false);
    gameOverPanel.SetActive(false);
}
```

SLIDE 18: Event Subscription for UI
------------------------------------
```csharp
void OnEnable()
{
    GameManager.Instance.OnScoreChanged += UpdateScore;
    GameManager.Instance.OnTimerUpdated += UpdateTimer;
}

void OnDisable()
{
    if (GameManager.Instance != null)
    {
        GameManager.Instance.OnScoreChanged -= UpdateScore;
        GameManager.Instance.OnTimerUpdated -= UpdateTimer;
    }
}
```

SLIDE 24: Debugging UI
-----------------------
Common issues:
- Button not responding → Check Raycast Target
- Text not showing → Check font asset assigned
- Panel not visible → Check active state
- Wrong panel showing → Check method calls

Use Debug.Log in button methods!

SLIDE 25: UI Best Practices
----------------------------
- Keep UIManager focused on UI
- Use events for updates
- Don't put game logic in UI
- Test all buttons
- Provide visual feedback
- Consider accessibility
