SLIDE 8: Common Final Issues
-----------------------------
"Game feels slow"
→ Reduce delays, speed up animations

"Clicks not registering"
→ Check raycast, colliders, input delay

"Score not updating"
→ Verify event subscriptions

"Music overlapping"
→ Stop previous before playing new

SLIDE 9: Sprint Task 1: Full Playtest
--------------------------------------
Play your game for 5 minutes:
- Note any bugs
- Note any awkward moments
- Note any missing feedback
- Note anything that feels wrong

Write down issues to fix!

SLIDE 10: Sprint Task 2: Bug Fixing
------------------------------------
Fix critical issues:
- Crashes
- Softlocks
- Missing functionality
- Broken UI
- Audio issues

Don't add new features - FIX bugs!

SLIDE 11: Sprint Task 3: Polish Pass
-------------------------------------
Improve feel:
- Adjust timing values
- Tune force values
- Balance audio levels
- Smooth animations
- Add missing feedback

Small changes, big impact!

SLIDE 12: Sprint Task 4: Build
-------------------------------
Create executable:
1. File > Build Settings
2. Add all scenes
3. Select platform (Windows/Mac)
4. Player Settings:
   - Product Name: "WallBreak 3D"
   - Company Name: Your name
   - Icon (optional)
5. Click Build
6. Test the build!
